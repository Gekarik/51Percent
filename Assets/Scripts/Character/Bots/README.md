# Adaptive Bot System

Система адаптивных ботов для io-игры 51Percent. Боты имитируют поведение реальных игроков с настраиваемой агрессивностью и умным принятием решений.

## Основные компоненты

### 1. BotState (enum)
Состояния бота:
- **Idle** - ожидание, анализ ситуации
- **Expand** - расширение территории безопасными трейлами  
- **Collect** - сбор монеток и бустеров
- **Attack** - атака чужих трейлов
- **Escape** - побег от опасности
- **Return** - возврат на безопасную территорию

### 2. BotStateConfig
Конфигурация поведения бота:

#### Пороги активации состояний (0-100):
- `expandThreshold` - порог для расширения территории
- `collectThreshold` - порог для сбора ресурсов  
- `attackThreshold` - порог для атаки трейлов
- `escapeThreshold` - порог для побега

#### Настройки поведения:
- `idleTime` - время ожидания в состоянии Idle
- `detectionRange` - радиус обнаружения целей
- `maxTrailLength` - максимальная длина трейла

#### Уровни агрессии (0-100):
- `overallAggression` - общая агрессивность
- `expandAggression` - агрессивность при расширении
- `collectAggression` - агрессивность при сборе ресурсов
- `attackAggression` - агрессивность при атаке

### 3. SituationAnalyzer
Анализирует ситуацию на карте:
- Поиск ресурсов поблизости
- Обнаружение уязвимых вражеских трейлов
- Определение угроз от других игроков
- Поиск безопасных зон для расширения
- Оценка приоритетов состояний

### 4. AdaptivePathProvider
Умная навигация:
- Движение к ресурсам
- Движение к конкретным гексам
- Следование по маршруту
- Автоматическое переключение целей

### 5. AdaptiveBotController  
Основной контроллер ИИ:
- Цикл принятия решений каждые 0.5 секунд
- Система приоритетов состояний
- Случайность на основе агрессивности
- Автоматические переходы между состояниями

### 6. AdaptiveBot
Главный класс бота, наследует CharacterAbstract

### 7. AdaptiveBotSpawner
Спавнер с поддержкой preset'ов конфигураций

## Использование

### Создание бота в коде:
```csharp
// Создать GameObject с компонентами:
// - AdaptiveBot
// - AdaptiveBotController  
// - AdaptivePathProvider
// - Mover, Conquester, Grabber (стандартные)

var bot = GetComponent<AdaptiveBot>();
bot.InitAI(hexGridProvider);
```

### Настройка через Inspector:
1. Добавить AdaptiveBotSpawner на сцену
2. Создать preset'ы BotStateConfig
3. Назначить массив конфигураций в spawner

### Примеры конфигураций:

#### Агрессивный бот:
```csharp
attackThreshold = 20;
attackAggression = 90;
escapeThreshold = 70;
overallAggression = 80;
```

#### Осторожный сборщик:
```csharp
collectThreshold = 30;
collectAggression = 80;
attackThreshold = 80;
attackAggression = 20;
escapeThreshold = 95;
```

#### Территориальный расширитель:
```csharp
expandThreshold = 40;
expandAggression = 90;
attackThreshold = 60;
maxTrailLength = 6;
```

## Особенности для WebGL

- Нет статических переменных
- Каждый бот имеет уникальный Random с собственным семенем
- Все данные хранятся в instance-переменных
- Совместимость с WebGL-сборкой

## Система принятия решений

1. **Критические ситуации** (высший приоритет):
   - Побег при обнаружении угрозы

2. **Оценка приоритетов**:
   - Каждое состояние получает оценку 0-100
   - Применяется фактор агрессивности
   - Добавляется случайность ±10-20

3. **Выбор состояния**:
   - Состояние с максимальным приоритетом
   - Минимальный порог 30 для активации
   - Принудительная смена при долгом бездействии

4. **Выполнение состояния**:
   - Вход: создание маршрута/цели
   - Исполнение: следование к цели
   - Выход: возврат в Idle при завершении

## Отладка

Для мониторинга состояния бота:
```csharp
var bot = GetComponent<AdaptiveBot>();
Debug.Log($"Bot State: {bot.GetCurrentState()}");
```

Настройка агрессивности в runtime:
```csharp
var config = bot.GetConfig();
config.attackAggression = 50;
```
