# Организация проекта

Текущее устройство игры и цепочки выполнения описаны в [карте проекта](project-map.md). Предложения по изменению архитектуры и порядок рефакторинга — в [разборе от 17 сентября 2026](architecture-review-2026-09-17.md).

Ассеты проекта находятся в `Assets/51_Percent` и разделены по типу.
Сторонние пакеты сохраняют собственную структуру вне этой папки.

| Папка | Содержимое |
| --- | --- |
| `Scripts` | C#-код, внутри — по назначению |
| `Tests/EditMode` | Проверки переходов фазы матча без сцены, отдельная assembly `51Percent.EditMode.Tests` |
| `Tests/PlayMode` | Проверки взаимодействий в Unity, отдельная assembly `51Percent.PlayMode.Tests` |
| `Prefabs` | Готовые объекты; `Characters` — персонажи, `Grid` — клетки, `Collectibles/Boosters` — бустеры, `Collectibles` — монеты, `UI/Elements` — элементы интерфейса, `Props` — визуальные объекты, `Cameras` — камеры |
| `Models` | Импортируемые модели FBX |
| `Meshes` | Отдельные меши `.asset`; `Generated` — результат HexPrismMeshCreator |
| `Sprites` | Изображения для спрайтов и UI |
| `Materials`, `PhysicsMaterials`, `Shaders` | Материалы, физические материалы и шейдеры |
| `Animations`, `Animators` | Клипы и контроллеры анимации |
| `ScriptableObjects` | Ассеты настроек; их C#-классы находятся в соответствующих разделах Scripts |
| `Scenes` | Игровые и проверочные сцены |

## Скрипты

- Все интерфейсы хранятся в `Scripts/Interfaces`, включая `IHexView`.
- `UI` содержит отображение и управление интерфейсом, включая `PlayerStatsPresenter`, `PlayerStatsView`, реестр иконок усилений и `UI/LeaderBoard`.
- `LeaderBoard` содержит модель рейтинга и его записи; представления находятся в UI.
- `Entities/Characters` содержит поведение и отображение персонажа, включая реестр его анимаций, `SocketType` и `AnimatorParams`. Здесь же находится модель монет/убийств `PlayerStats`: `CharacterBase` создаёт её на экземпляр персонажа и предоставляет через `LifeStats`. Отдельный `PlayerStatsComponent` удалён; модель используется и игроком, и ботами.
- `Entities/Collectibles` содержит подбираемые предметы и эффекты усилений. В `Entities/Collectibles/Boosters` находятся общие типы бустеров `BoosterId` и `BoosterEndReason`, используемые правилами и представлением.
- `AI` содержит поведение ботов и настройки их имён.
- `Spawners` содержит создание объектов и настройки точек спавна.
- `Core` содержит инициализацию и общие игровые службы; `Gameplay` — игровые правила; `Grid` — сетку.
- `Editor` содержит инструменты редактора, `Dev` — средства ручной проверки, `Utils` — общие вспомогательные классы.

## Правила размещения

19 сентября 2026 выполнен перенос шести скриптов через Unity с сохранением содержимого и `.meta`; следующим согласованным пакетом удалён `PlayerStatsComponent` и добавлен Play Mode тест жизненного цикла статистики. Результаты и границы проверок — в карте проекта.

20 сентября 2026 по файлам сверена раскладка префабов, выполненная пользователем, и добавлены тесты фазы матча, бустеров, выбывания и территории. Новые Play Mode тесты ещё не запускались. Простые будущие переносы пользователь предпочитает выполнять сам по предложенному списку.

Сначала выбирай тип ассета, для скриптов — его ответственность. Не собирай код, иконки и префабы одной механики в общую папку. Не создавай подпапки заранее без содержимого. Часто используемые папки и поисковые запросы можно добавить в Favorites окна Project.

Переноси ассеты средствами Unity с сохранением `.meta`. При изменении пути проверяй строковые ссылки в инструментах редактора. Переорганизацию папок выполняй отдельно от изменений игрового поведения.
